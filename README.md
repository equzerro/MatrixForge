# MatrixForge v0.1-Demo

MatrixForge — лёгкое математическое приложение для выполнения сложных вычислений.

Проект относится к направлению **сложных математических операций** и демонстрирует две ключевые функции:

- символьное дифференцирование математических выражений;
- решение разреженных систем линейных уравнений методом сопряжённых градиентов.

---

## Описание проекта

MatrixForge создан как демонстрационная версия математического ядра без использования внешних библиотек.

Главная идея проекта — показать, как сложные математические алгоритмы могут быть реализованы самостоятельно:

- собственный парсер математических выражений;
- построение абстрактного синтаксического дерева;
- применение правил символьного дифференцирования;
- работа с разреженными матрицами;
- решение СЛАУ методом сопряжённых градиентов.

Проект подходит для студентов, преподавателей и начинающих разработчиков, которые хотят понять, как математические программы работают изнутри.

---

## Проблема

Многие математические программы и библиотеки являются тяжёлыми, требуют установки большого количества зависимостей или являются платными.

Например:

- MATLAB — мощный, но платный инструмент;
- Wolfram Mathematica — функциональный, но требует лицензии;
- крупные Python-библиотеки могут быть избыточны для учебных проектов.

MatrixForge решает эту проблему за счёт лёгкой реализации на чистом Python.

## Основные функции

### 1. Символьное дифференцирование

Программа принимает математическое выражение и возвращает его производную.

Пример выражения:

text
sin(x^2) + 3*x

Пример результата: f'(x) = ((cos((x ^ 2)) * ((2 * (x ^ 1)) * 1)) + ((0 * x) + (3 * 1)))
Математически это соответствует: 2*x*cos(x^2) + 3

2. Решение разреженной СЛАУ
MatrixForge умеет решать систему линейных уравнений вида: Ax = b
Для этого используется:
разреженное хранение матрицы;
метод сопряжённых градиентов.
Пример результата: Решение: [0.5357, 1.1429, 1.6071, 1.4018]
Итераций: 4

Технологии
Проект реализован на языке: Python 3.10+
Используются только стандартные библиотеки Python: re , math
Внешние зависимости не требуются.

Алгоритмическая особенность
Главная техническая особенность проекта — собственная реализация математического ядра.

В MatrixForge реализованы:

Парсер рекурсивного спуска
Разбирает выражение с учётом приоритета операций.

AST — абстрактное синтаксическое дерево
Представляет математическое выражение в виде дерева.

Символьное дифференцирование
Применяет правила производной:

производная суммы;
производная разности;
производная произведения;
производная частного;
производная степени;
производная функций sin, cos, exp, ln.
Разреженная матрица
Хранит только ненулевые элементы.

Метод сопряжённых градиентов
Используется для решения систем линейных уравнений. 


Системные требования

Windows / Linux / macOS;
Python версии 3.10 или новее;
128 МБ оперативной памяти;
интернет не требуется;
внешние библиотеки не требуются.


Установка
Шаг 1. Скачать проект
Скачайте файл: matrixforge.py
или клонируйте репозиторий: git clone https://github.com/equzerro/matrixforge
Перейдите в папку проекта: cd matrixforge

Шаг 2. Запустить программу
В командной строке выполните: python matrixforge.py
Если команда python не работает, попробуйте: py matrixforge.py
или: python3 matrixforge.py

Быстрый старт
После запуска появится меню: 
==================================================
       MatrixForge v0.1-Demo
==================================================

1 — Символьная производная
2 — Решить разреженную СЛАУ
0 — Выход
>>>

Пример 1. Найти производную
Выберите пункт: 1
Введите выражение: sin(x^2) + 3*x
Программа выведет производную.

Пример 2. Решить СЛАУ
Выберите пункт: 2
Программа запустит демонстрационную систему 4x4 и выведет решение.

Выход из программы
Введите: 0


Поддерживаемые операции
Операция	            Пример
Сложение	            x + 2
Вычитание	            x - 5
Умножение	            3*x
Деление	              x/2
Степень	              x^2
Синус	                sin(x)
Косинус	              cos(x)
Экспонента	          exp(x)
Натуральный логарифм	ln(x)

Важно: умножение нужно писать явно.

Правильно: 3*x
Неправильно: 3x
